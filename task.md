# Реализация низкоуровневого обработчика SIGFPE
- Настройте обработчик сигнала SIGFPE с помощью системного вызова sigaction с флагом SA_SIGINFO.
- Извлеките из контекста ucontext_t текущий адрес RIP.
- Сравните байты по адресу RIP с таблицей известных паттернов инструкций div/idiv (байты и длина из дампа objdump -d). Если совпадение найдено — считайте инструкцию распознанной.
- Запишите 0 в регистры RAX (частное) и RDX (остаток) в сохранённом контексте; продвиньте RIP на длину распознанной инструкции, чтобы CPU перешагнул сбойный div/idiv при возврате из обработчика.
# Демонстрация влияния оптимизатора
Реализуйте два тестовых сценария:
A: переменная-делитель объявлена как volatile на всём протяжении — компилятор не может оптимизировать ни деление, ни последующую проверку.
B: значение 0 читается из volatile-переменной в обычную локальную переменную, затем выполняется деление. Компилятор может применить оптимизацию на основе Undefined Behavior.

В каждом сценарии после деления выполните проверку if (b == 0) и выведите соответствующий результат ("b is 0" или "b is NOT 0").
